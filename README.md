# にほんご Quest 🎌

A browser game that helps a young learner (about 10 years old) **build Japanese vocabulary, keep reading hiragana & katakana, and put verbs and particles together into sentences**. It is based on the class slides: *Past Tense Negatives*, *List of Interesting Words*, and *Phrases I See & Hear*.

No install, no build, no internet needed. **Just open `index.html`** in any modern browser (Chrome, Edge, Safari, Firefox; phone, tablet or computer).

To put it online (for example on a tablet), turn on **GitHub Pages** for this repository (Settings → Pages → deploy from the branch, root folder) and open the page address.

## How it plays

1. **Pick a subject** (the focus of everything): ⭐ *From My Class* (the words from the slides), Food, School, Family, People & Jobs, Town & Travel, Shopping, Parties & Events, Animals, Play & Hobbies, Feelings, Days & Times, or Action Words (verbs). Or 🌈 surprise me with everything.
2. **Pick a game** for that subject:

| Game | What it trains |
| --- | --- |
| 🎲 **Mixed Adventure** | A fresh mix of every kind of question |
| 🌟 **Word Quest** | 9 quiz types: picture → Japanese, Japanese → picture, listen → picture, listen → word, Japanese ↔ English, **missing kana**, **spell it with kana tiles**, hiragana-or-katakana |
| 🧩 **Sentence Builder** | Build a sentence from an English meaning using tiles: `きのう わたし は あさごはん を たべ ませんでした`. Particles are colour-coded; the action goes last |
| 🎯 **Particle Power** | Pick the missing particle (は を に へ で と の が) and see *why* it fits |
| 🧱 **Past Tense Lab** | The slide guide as games: THING (です) or ACTION (ます)? Pick the ending, snap the bricks together (`ません` + `でした`), spot the wrong-family ending, answer a past question with "no" |
| 🃏 **Memory Match** | Flip cards to match Japanese words and pictures |
| 🔤 **Script Sorter** | Is it ひらがな or カタカナ? |
| 📚 **Study Cards** | Picture, sound, romaji, kanji from the slides, plus example sentences using the word with particles |

3. **Collect stickers** 🏷️ (one per word), earn ⭐ stars, XP levels, 🔥 streaks and 🏅 badges.

## Romaji on / off

The **Romaji** switch is always in the top bar. When it is on, small English letters float above every Japanese word, particle and ending (like the slides). Turn it off to practise real reading. It switches instantly, even in the middle of a game.

## Different questions every time

Every round is built by a **variety engine** (`js/store.js`). It remembers the questions asked recently, scores every possible question by how new it is, never repeats a question from the round before, takes only one question per word where it can, and rejects any set that matches a recent round. Sentences are generated by combining subjects, particles, objects, places, verbs and time words, so there are thousands of different ones. A wrong word comes back later in the same round as a *second chance* in a different quiz style.

## Sounds and pictures

* Sound effects and a gentle looping tune are **synthesized live** (Web Audio), so there are no audio files.
* Words and sentences are read aloud with the browser's **Japanese voice** (Speech Synthesis). If the device has no Japanese voice, the listening questions are skipped automatically. Voice speed can be slowed down in ⚙️ Settings.
* Pictures are emoji, so everything works offline.
* Everything can be switched off in ⚙️ Settings (sound, music, voice, animations).

## Add your own words

All content is plain data in `js/data.js`:

```js
// [id, kana, english, emoji, article, extras]
['ringo', 'りんご', 'apple', '🍎', 'a'],
```

Romaji is generated automatically (macron style like the slides: `sensē`, `ōkii`, `jūkyū`). To make a word usable in sentences, add its id to the lists at the top of `js/sentences.js`.

## Code map

| File | Purpose |
| --- | --- |
| `js/data.js` | Subjects, words, verbs, particles |
| `js/kana.js` | Romaji converter, script detection, look-alike kana |
| `js/sentences.js` | Sentence generator (Japanese tiles + matching English) |
| `js/store.js` | Saved progress + the variety engine |
| `js/sfx.js` | Sound effects, music, Japanese speech |
| `js/ui.js` | Shared UI helpers (tiles, confetti, modals) |
| `js/qwords.js`, `js/qgrammar.js` | All question types |
| `js/games.js` | Round runner, Memory Match, Study Cards, Sticker Book, results |
| `js/app.js` | Home, subject pages, settings, rules sheet, kana chart |

Progress is saved only in this browser (`localStorage`); nothing is sent anywhere.

## Tests

```bash
node tests/test-data.js       # romaji + word data checks
node tests/test-sent.js all   # prints sample generated sentences for proofreading
node tests/variety.js         # needs Playwright: proves rounds never repeat
node tests/playthrough.js     # needs Playwright: plays every game in every subject
```
